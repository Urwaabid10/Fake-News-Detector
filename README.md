# Fake News Detector

A simple tool to analyze news credibility using Google Gemini AI.

## Setup
1.  Get a Google Gemini API Key.
2.  Open `config.js` and paste your key there.

## How to Run
1.  Open a terminal in this folder.
2.  Run:
    ```bash
    npx serve
    ```
3.  Open the link shown (usually `http://localhost:3000`).
